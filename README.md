# Vol Strategy Backtester

Backtests option strategies that try to harvest SPY volatility mispricing: straddles, strangles,
calendar spreads and a volatility-risk-premium signal (implied vol vs a forecast of realised vol).
The design goal is to show how much of the premium survives:
- fills at bid/ask, with a cap on contracts per option per day;
- greek and stress-loss budgets;
- an honest capital base with real margin calls;
- the 2018–2025 volatility shocks.

> **Educational project — not financial advice.** It places no orders and makes no claim that any
> strategy is profitable.

**Status: milestones 0 to 3 are committed, and so are parts A and B1 of milestone 4 (signals,
strategies, and a forecast test that is pre-registered and not yet scored).** Milestones 0 and 1
built the scaffold, the design and decision records, and the option-chain data layer with its
quality flags. Milestone 2 prices
every quote (Black-76 on a de-Americanised parity forward, implied vols, smiles); the findings of
its four review rounds are fixed. Milestone 3 runs a strategy day by day: fills at the next close in
whole cents, settlement and early exercise, one mark per lot per day, a daily delta hedge and
cash that reconciles exactly, written to a ledger whose bytes depend only on its inputs, its
config, its commit and its code. An adversarial review of it found a wrong NAV in one diagnostic
mode, a run id that did not name the code and six test gaps, among other things. Those three are
fixed and each has a test; what is not fixed is listed in the ledger. A 14-year run (2010-2023)
takes 18 to 21 s when the machine is not busy and 34 to 39 s when it is, against ADR-0001's 60 s
limit. Its reference strategy, a rolling short straddle, is a diagnostic that exercises the engine
and not a result: no P&L, NAV or Sharpe ratio is reported for it, and none for any run past 2019
([walkthrough](docs/milestones/03-daily-engine.md), [ledger](docs/validation/03-ledger.md)).
Milestone 4 adds the signals (realised variance, a HAR forecast of it, 30-day implied vol and their
log ratio), four strategy structures with their entry and exit rules, and a test of the HAR forecast
against a naive one whose threshold and data were fixed before it is scored
([ledger](docs/validation/04-ledger.md)). Its walkthrough comes with part B2. Until
the owner decides on ADR-0008's proposed per-expiry rate, strategies trade expiries of at most 180
days ([milestone 2](docs/milestones/02-pricing-core.md), [its ledger](docs/validation/02-ledger.md)).
No strategy results exist yet. The results table below fills in at milestone 6, and every number in
it will be regenerated by the pipeline and independently re-measured.

## Run

Python 3.12 via [uv](https://docs.astral.sh/uv/); Node 22 for the app.

```bash
uv sync                                         # exact pins from uv.lock
uv run pytest -q                                # tests
uv run python tools/build_notebooks.py --check  # notebooks in sync with src/
uv run python tools/export_app_data.py          # write app/public/data/*.json
```

```bash
cd app
npm ci
npm run dev      # local app
npm run verify   # lint + tests with coverage thresholds + production build
```

```bash
uv run --group diagrams python tools/diagrams/build.py docs/architecture/specs --out docs/architecture/out   # specs -> out/
npm ci --prefix tools/screenshots                # then, from tools/screenshots: npm run capture
```

## Data

Raw vendor data is **never committed**. Loaders read it from `VOL_DATA_DIR`, which defaults to
`~/data/vol-projects`.

| Use | Source | Licence / terms |
|---|---|---|
| SPY option chains 2010–2023 | OptionsDX SPY end-of-day, re-hosted on Kaggle as `dudesurfin/spy-options-eod-volatility-surface-2010-2023` | Vendor data: not redistributed here. No OptionsDX terms are known; Kaggle lists the dataset under MIT ([DATA.md](DATA.md)) |
| SPY option chains 2019–2026; its 2024-01-02 to 2026-10-26 is the out-of-sample holdout ([ADR-0010](docs/adr/0010-evaluation-protocol.md)) | DoltHub [`post-no-preference/options`](https://www.dolthub.com/repositories/post-no-preference/options) | CC BY-SA 4.0 |
| SPY prices and dividends | yfinance | Yahoo terms (the yfinance README: its API is "intended for personal use only"): not redistributed in bulk; the four SPY closes of `surface_frames.json` are committed ([DATA.md](DATA.md)) |
| Risk-free rate | FRED `DGS3MO` | Public |
| VIX history (regimes) | Cboe | Cboe's website terms: personal, non-commercial use; copying, storing, deriving from or publishing it needs Cboe's prior written consent. Not redistributed in bulk, but this repository does publish VIX closes and figures computed from Cboe's index files, in the 14 files that [DATA.md](DATA.md) lists for owner review (13 of them hold VIX closes) |

## Data and licences

The data is not covered by this repository's MIT licence. [DATA.md](DATA.md) lists each source with its terms and a link, and says what is committed (small derived tables, the app JSON, real values in docs) and what never is (the downloaded vendor files). Figures derived from DoltHub carry a CC BY-SA 4.0 notice: the short form that DATA.md defines sits under the title of each document that quotes them (DATA.md lists the documents), and the app data has its own in [app/public/data/LICENSE-DATA.md](app/public/data/LICENSE-DATA.md). `tools/licensing/check_tracked_data.py` fails the build of a commit that would take a raw vendor file or a data file over 50 MB.

## Layout

```
src/volbt/        all logic (data, pricing, signals, strategies, risk, engine, analytics, export)
tests/            pytest; hand-worked expected values, mutation-checked
notebooks/        generated from src/ by tools/build_notebooks.py (a test keeps them in sync)
tools/            notebook builder, app-data exporter, blender/ render scripts
app/              Vite + React 19 + TypeScript + three.js; only renders app/public/data/*.json
docs/prfaq.md     Amazon-style PR/FAQ, written working backwards
docs/adr/         architecture decision records
docs/architecture/ diagram specs (YAML) and Mermaid diagrams
docs/concepts/    theory notes with the maths
docs/milestones/  per-milestone walkthroughs and interview questions
docs/validation/  adversarial-review ledgers
```
