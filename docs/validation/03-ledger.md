## The engine bug the tests found

With `hedge.mode = never`, shares delivered by an *early* assignment were never liquidated. ADR-0003 §5 says that liquidation follows its point 3, which creates a share-sale order for shares delivered at expiry. A test that asserted this was kept as a strict xfail while the engine was wrong. The fix, in `Run.step_10_early` (`src/volbt/engine/loop.py:697-701`), creates a `share_liquidation` order when the early event is decided; the shares are booked before *t+1* opens and sold at the *t+1* close. The test that now passes is `tests/test_engine_early.py:211`, and mutant 39 (the order removed) fails it.
